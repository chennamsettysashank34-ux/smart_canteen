# AI agent collaboration

1. Ask the Tech Lead agent to inspect the repository and define a narrow task contract.
2. Assign one implementation area to one specialist. Avoid simultaneous edits to the same files.
3. Ask QA/Security to review the diff and test the stated scenarios.
4. Ask Tech Lead to reconcile API contracts and data types before merge.
5. Review the diff yourself; never merge solely because an agent says a task is complete.

Recommended tasks are independent where possible: UI design, engine tests, schema review, API route work, and documentation. Cross-cutting changes should have one owner.
